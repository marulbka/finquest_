# ФінКвест — прототип застосунку

Гейміфікований застосунок фінансової грамотності для молоді 14–25 років.
Навчальний проєкт з дисципліни «Діджитал підприємництво», КНЕУ.

**Відкрити застосунок:** `https://ВАШ-ЛОГІН.github.io/finquest/` (з’явиться після кроку 3 інструкції нижче).

## Що вміє прототип

| Розділ | Можливості |
|---|---|
| Реєстрація (3 кроки) | Ім’я, вік (14–17 / 18–25), місячний бюджет → ціль: назва, сума, дата, стартова сума, іконка → підключення картки (демо) |
| Головна | Бюджет місяця, «скільки можна витратити сьогодні», серія днів у бюджеті, діаграма витрат за категоріями, графік за 7 днів, ручне додавання витрат, список останніх витрат, порада дня |
| Ціль | Кільце прогресу, план «на день / тиждень / місяць», статус «у графіку / відставання», нагороди за 25–50–75–100%, поповнення, історія, редагування |
| Тренажер | Порівняння депозиту, ОВДП і «грошей на картці» на віртуальних грошах: податки, інфляція, капіталізація, дострокове зняття, журнал угод |
| Навчання | 6 текстових уроків (бюджет 50/30/20, подушка безпеки, депозит, ОВДП, складний відсоток та інфляція, шахраї) з тестом після кожного |
| Профіль | Рівні та XP, 12 нагород, керування карткою й бюджетом, експорт даних, скидання |
| Батьківський режим | Вмикається з PIN-кодом; кабінет батьків показує прогрес цілі, частку бюджету, ліміти за категоріями, уроки; батьки можуть надіслати бонус до цілі. Окремі покупки дитини батьки не бачать |

Кнопка **«Переглянути з демо-даними»** на першому екрані одразу заповнює застосунок прикладом (зручно для захисту).

## Безпека та обмеження

- Застосунок **ніколи не запитує** повний номер картки, CVV, PIN чи коди з SMS. Для «підключення» достатньо назви банку й (за бажанням) 4 останніх цифр.
- Підключення картки **демонстраційне**: витрати генеруються як приклад. У реальному продукті витрати отримували б через офіційні API банків (наприклад, monobank має відкритий API для виписок) або через open banking.
- Сервера немає: усі дані зберігаються лише в браузері (localStorage) на пристрої користувача. На іншому телефоні чи в іншому браузері дані будуть свої.
- Ставки в тренажері — приклад, їх можна змінити. Застосунок не є фінансовою порадою.

## Як опублікувати на GitHub (без програмування)

### Крок 1. Створіть репозиторій
1. Увійдіть на [github.com](https://github.com).
2. Угорі праворуч натисніть **«+» → New repository**.
3. **Repository name:** `finquest`.
4. Оберіть **Public** (GitHub Pages безкоштовно працює для публічних репозиторіїв).
5. Галочку «Add a README file» **не ставте**.
6. Натисніть **Create repository**.

### Крок 2. Завантажте файли
1. Розпакуйте архів `finquest.zip` на комп’ютері.
2. На сторінці нового репозиторію натисніть посилання **«uploading an existing file»**.
3. Відкрийте розпаковану папку `finquest` і перетягніть у вікно браузера **весь її вміст**: файли `index.html`, `icon.svg`, `manifest.webmanifest`, `README.md` і папки `css` та `js`.
   - Важливо: перетягувати треба вміст папки, а не саму папку `finquest`, щоб `index.html` лежав у корені репозиторію.
   - Перетягування папок працює в Chrome та Edge. Якщо папки не завантажуються, див. розділ «Якщо щось не так».
4. Унизу в полі «Commit changes» напишіть, наприклад, `Перша версія прототипу`, і натисніть **Commit changes**.

### Крок 3. Увімкніть GitHub Pages
1. У репозиторії відкрийте вкладку **Settings**.
2. У меню ліворуч оберіть **Pages**.
3. У блоці **Build and deployment**: Source — **Deploy from a branch**, Branch — **main**, папка — **/ (root)**. Натисніть **Save**.
4. Зачекайте 1–3 хвилини й оновіть сторінку. Угорі з’явиться посилання **«Your site is live at https://ВАШ-ЛОГІН.github.io/finquest/»**.

### Крок 4. Відкрийте на телефоні
Відкрийте посилання в браузері телефона. Щоб застосунок виглядав як звичайний:
- **iPhone (Safari):** «Поділитися» → «На екран Додому».
- **Android (Chrome):** меню ⋮ → «Додати на головний екран».

### Крок 5. Як вносити зміни
1. Відкрийте потрібний файл у репозиторії (наприклад, `js/data.js`).
2. Натисніть значок олівця ✏️ («Edit this file»).
3. Внесіть зміни → **Commit changes**. Сайт оновиться за 1–2 хвилини.

### Робота в команді
**Settings → Collaborators → Add people** — додайте одногрупників за їхнім логіном на GitHub, і вони теж зможуть редагувати файли.

### Якщо щось не так
- **Сайт показує 404.** Перевірте, що `index.html` лежить у корені репозиторію, а не в папці `finquest/`. Зачекайте ще кілька хвилин.
- **Сторінка без оформлення.** Не завантажилися папки `css` або `js`. Створіть файли вручну: **Add file → Create new file**, у назві введіть `css/styles.css` (косу риску GitHub перетворить на папку), вставте вміст файлу з архіву, **Commit changes**. Так само для `js/data.js` і `js/app.js`.
- **Хочу почати з нуля.** У застосунку: Профіль → «Скинути все».

## Структура файлів

```
finquest/
├── index.html            — сторінка застосунку
├── css/styles.css        — оформлення
├── js/data.js            — тексти уроків, категорії, нагороди, поради (легко редагувати)
├── js/app.js             — логіка: екрани, розрахунки, збереження даних
├── manifest.webmanifest  — щоб застосунок можна було додати на головний екран
├── icon.svg              — іконка
└── README.md             — ця інструкція
```

Щоб запустити на комп’ютері, достатньо двічі клацнути `index.html`. Шрифти Manrope та Inter підвантажуються з Google Fonts; без інтернету застосунок працює зі стандартним шрифтом системи.

## Що редагувати найчастіше

- **Тексти уроків і тестів** — масив `LESSONS` у `js/data.js`.
- **Категорії витрат** — масив `CATEGORIES` у `js/data.js`.
- **Поради дня** — масив `TIPS` у `js/data.js`.
- **Кольори** — змінні на початку `css/styles.css` (`--primary`, `--sky`, `--indigo`, `--ink`) та кольори категорій у `js/data.js`.

## Факти в уроках (станом на листопад 2026 року)

- Податки на відсотки за депозитом: 18% ПДФО + 5% військового збору.
- Дохід фізичних осіб від ОВДП не оподатковується; номінал однієї облігації — 1 000 грн.
- Вклади фізосіб під час воєнного стану й три місяці після нього гарантуються на 100%, потім — до 600 000 грн.

Ці цифри можуть змінитися, тому перед захистом проєкту варто їх перевірити.
